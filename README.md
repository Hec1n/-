# ことば — японский каждый день

Статический сайт без сборки: откройте index.html или разместите через GitHub Pages. Слова, правила и кандзи находятся в data.js. Результаты и список ошибок сохраняются только в браузере на этом устройстве.

## Обновление после занятия

После введения новых слов добавлять их в rawWords, без дублей, с проверенной страницей источника, номером серии и статусом «введено». Не включать слова, которые лишь предложены на будущее. Обновлять RULES при введении конструкции; KANJI — при добавлении новых карточек. В кандзи указывать чтение конкретного слова, а не обещать полный список чтений знака.

Сверять данные с Japanese/Прогресс.md в учебной папке. Проверить `node --check data.js` и `node --check app.js`, затем отправить изменения в main. Workflow публикует сайт автоматически. Если Pages ещё не включены, выбрать Settings → Pages → Source → GitHub Actions.

Автопроверка принимает перечисленные варианты ответа, игнорирует регистр, ё/е, лишние пробелы и конечную пунктуацию. Она не заменяет проверку свободного перевода преподавателем. Для суффиксов ～ необязателен; для катаканы требуется стандартное написание.
